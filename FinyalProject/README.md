# Анализ и прогнозирование цен на такси (Yandex Go / Яндекс GO)

## Задача проекта
Построить модель машинного обучения для предсказания стоимости поездки на такси
на основе таких факторов, как расстояние, тариф, погода, время суток и платформа.

## Данные
Датасет `Taxi Price 1.csv` содержит записи о поездках с полями:
- **Компания** - название сервиса (Yandex Go и остальные)
- **Эконом** - тариф поездки (Эконом, Комфорт, Комфорт+)
- **Расстояние** - дистанция в км
- **Время заказа** - время суток (ЧЧ:ММ)
- **Погода** - погодные условия (Ясно, Дождь, Снег, Облачно)
- **IOS/Android** - платформа клиента
- **Цена** - стоимость поездки в сомах *(целевая переменная)*
- **Процент на телефоне** - заряд батареи клиента
- **сом за км** - удельная стоимость
- **Время поездки/мин** - длительность поездки
- **Повышенный спрос** - флаг повышенного спроса

## Методы
Обучены три модели из разных семейств:
1. **LinearRegression** - базовая линейная модель
2. **RandomForestRegressor** - ансамбль деревьев (бэггинг)
3. **GradientBoostingRegressor** - ансамбль деревьев (бустинг)

Для лучшей модели проведена **кросс-валидация cv=5**.

## Структура проекта
```
├── main.py           - запуск полного pipeline
├── data_loader.py    - загрузка и первичный просмотр данных
├── preprocessing.py  - очистка, кодирование, нормализация
├── eda.py            - разведочный анализ и графики (EDA)
├── models.py         - обучение моделей, кросс-валидация, метрики
├── evaluate.py       - финальная оценка лучшей модели
├── dataset.csv       - исходный датасет
└── plots/            - сохранённые графики PNG
```

## Метрики оценки
- **MAE** - средняя абсолютная ошибка
- **RMSE** - корень из средней квадратичной ошибки
- **R²** - коэффициент детерминации

## Выводы
Целевая переменная (Цена) имеет правостороннее распределение: большинство поездок
стоят 200–650 сом, встречаются выбросы при длинных маршрутах в условиях повышенного
спроса или плохой погоды. Наиболее важными признаками для предсказания цены
являются расстояние поездки и сом/км, что можно обьединить в одну категорию,
я полагаю. На втором месте - длительность поездки.
